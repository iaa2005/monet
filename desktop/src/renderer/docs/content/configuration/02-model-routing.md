title: Model routing

Not everything the app does is the conversation. Writing a memory note after a
turn, the nightly consolidation, the Reflect digest, drafting a routine — all of
these call a model, and none of them needs your best one.

**Settings → Advanced → Background model** points that work at any configured
provider and model. Leave it on the active provider, or send it to something
cheap — including a local model, which makes it free.

If the provider you chose is later deleted, background work falls back to the
active provider rather than silently stopping.

## Per-routine models

A routine can pin its own provider and model, independently of both the chat
model and the background model. See **Routines**.
