# Предпочтения

## Стиль работы

> 2026-07-06

- **План перед кодом.** Использовать strict-plan-execution. Не писать код без явного разрешения.
- **Коммиты по каждому критерию.** После каждого `[x]` в плане — git-коммит.
- **Безопасность run-команд.** Проверять, что команды не удалят `.git/`, `package.json`, `tsconfig.json`.
- **Не писать код без разрешения** — даже если кажется очевидным.

## Стиль кода

> 2026-07-06

- **Архитектурная чистота.** Проект должен быть масштабируемым, модули независимы.
- **Не создавать лишних кастомных компонентов.** Использовать shadcn/ui где возможно.
- **Автономность.** Папка `desktop/` должна работать без внешних зависимостей.

## Стек (предпочтения)

> 2026-07-06

- **TypeScript** — основной язык
